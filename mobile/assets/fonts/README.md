# Brand fonts

Drop the .ttf files here and load them in `app/_layout.tsx` via `expo-font`.
Names must match `constants/fonts.ts`.

Playfair Display (headings, body):
- PlayfairDisplay-Regular.ttf
- PlayfairDisplay-Italic.ttf
- PlayfairDisplay-Bold.ttf

DM Sans (UI, buttons, eyebrows):
- DMSans-Regular.ttf
- DMSans-Medium.ttf
- DMSans-Bold.ttf
- DMSans-Black.ttf

Both are Google Fonts (OFL). Alternative: `npx expo install @expo-google-fonts/playfair-display @expo-google-fonts/dm-sans`.
